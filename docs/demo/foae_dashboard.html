Thresholds were fixed before the data was seen, and every constant was swept to a value that should break its mechanism — a constant whose breaking value changes nothing is dead code, not a parameter. That sweep caught one constant no experiment had ever read.

A later audit found three constants living in test files, outside the config audit. One of them sat about 14× above its break-even range and had been driving a claim to the wrong verdict; correcting it moved that claim from dead back to undetermined.

Seven tests in the suite fail on purpose. Each one encodes a falsified claim, so a green suite would mean a result had been quietly reversed.
